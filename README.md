产品概述
个人工作看板是一个单页 HTML 工具，把《将工作可视化》（Dominica DeGrandis）的方法落到个人日常：周看板负责计划和可视化，日看板负责执行，月历记录关键时间。
要解决的问题：工作任务有人催、有截止，总是挤掉个人项目；任务太大太模糊，难以启动；等待、插单、长期搁置的事情看不见。对应书中的五个时间窃贼：
时间窃贼
看板里的对策
在制品过多
进行中设上限，名额用格子显示，满了不能再拉新任务
未知的依赖
等待中单独一列，记录在等谁，超 7 天标红
计划外工作
任务可标为插单，统计插单占比
优先级冲突
周看板把任务安排到具体某天，日看板只做挑进来的事
被忽视的工作
21 天预警、30 天判为僵尸任务，逐张处理
目标用户：一个人同时推进工作与个人项目（写作、播客、求职等），希望个人项目也能稳定启动。
版本形态
• 本地版：一个 HTML 文件，浏览器直接打开，数据存在当前浏览器。
• 在线版：发布在 claude.ai，登录后打开，数据按账号私有并同步到云端，电脑和手机共用一份。
• 两个版本功能相同，可通过“备份”导出、导入数据互相迁移。
信息架构与数据模型
产品分三个视图，共用一份数据：周看板写入日计划，日看板读取日计划并产生计时记录，月历维护关键时间。

周看板
周看板只做计划与可视化，不出现番茄钟。从上到下依次是：顶栏、周节奏条、统计区、工具栏、看板。
顶栏
• 标题、新建任务、新建项目、月历、备份。
• 在线版右侧显示同步状态：已同步云端 / 同步中 / 同步失败 / 仅保存在本机。
周节奏条
• 上周 / 下周切换，非本周时显示“回到本周”。
• 七个日期格，今天高亮。每格两根小柱：蓝色 = 当天安排件数，绿色 = 已完成件数；下方显示“安排 N · ✓N”和第一条关键时间。
• 点日期格进入该天的日看板；把任务卡拖到日期格上 = 安排到那天。
统计区（三张卡）
• 工作、个人：大数字“完成 / 目标 件”+ 方块矩阵，每行 5 格，一格一件任务，实心 = 完成，空框 = 未完成，超过 25 件显示“+N”。不使用进度条。
• 僵尸任务：一次只显示停滞最久的一件（任务名、N 天没动、分类、所属项目），只有两个操作：
    1. 做十分钟：卡片滑出，开始 10 分钟计时；一开始计时就不再算僵尸。
    2. 放弃：二次确认后删除任务，若是子项目则一并从项目中移除。
• 僵尸卡左侧的处理矩阵：绿色 = 本周做过十分钟，灰色 = 本周放弃，红色虚线框 = 待处理。全部处理完显示“清空了”。
工具栏
• 分类筛选：全部 / 工作 / 个人，对周、日看板都生效。
• 次要指标一行小字：等待超 7 天、插单占比。
• 示例数据提示与“清空”。

日看板

顶部
• 返回周看板、日期标题、今天标记或“回到今天”、分类筛选、月历、前一天 / 后一天。
• 关键时间：当天在月历里记下的事项，以蓝色胶囊显示，带时间的显示时间。
• 计划与实际：两行 🍎，上行 = 计划，下行 = 实际，右侧写个数和时长；下方一条红色对比条（实际 ÷ 计划）；最右是“完成 N/N”和“启动次数”。
当天清单（左）
• 只显示安排到这一天的任务：来自周看板的“安排到…”、拖到日期格，或从右侧挑选、当天新建。不会自动出现其他任务。
• 每项：完成勾选框、标题、分类、难度、项目、插单、非待办时的状态；🍎 行（彩色 = 已做，灰色 = 计划未做，半透明 = 不足 20 分钟）；计划数 − / +（1–12）；▶ 20 分钟；+🍎 补记；−🍎 撤回补记；× 移出这一天。
• 困难重要任务额外显示：启动次数圆环、每次启动的小方块（深色 = 做满 20 分钟，浅色 = 提前结束，带框 = 当天）；计时时圆环变成 20 分钟倒计时。
• 已完成的项沉到底部、划线显示。
挑选区（右）
• 快速新建：标题 + 分类 + 难度，回车直接放进这一天。
• 候选任务 = 待办和进行中、未放进这一天的任务，分三组：⚡ 简单 · 马上就能做完 → 困难重要 · 启动一次就算赢 → 普通。
• 点一下放进左侧清单。
计时规则
• 同一时间只能有一个计时；只能在今天计时，其他日期用 +🍎 补记。
• 计时时底部固定计时条：任务名、倒计时、去今天、提前结束。刷新页面后计时继续；到点自动记满。
• 提前结束按实际分钟记录，仍计为一次启动。
简单任务动效
• 挑选区的简单任务：绿色边框 + 一道光来回扫过，⚡ 图标轻轻晃动，悬停时上浮放大，点击后滑入左侧，新项弹入。
• 勾选完成时弹出一圈彩色碎片，简单任务碎片更多。
• 系统开启“减少动态效果”时全部动画关闭。
月历
月历以弹窗打开，入口在周看板顶栏和日看板顶部（从日看板打开时定位到当天）。
• 左侧月视图：周一开头，上月 / 下月 / 今天；每格显示日期和前两条关键时间，多出的显示“+N”；今天高亮，选中格加框；手机宽度下只显示圆点。
• 右侧编辑区：选中日期的关键时间列表，按时间排序，未填时间的显示“全天”；时间（可不填）+ 内容，回车添加，× 删除；“打开日看板 ›”跳转到这一天。
• 联动：关键时间同时出现在周节奏条的日期格（第一条 + 条数）和日看板顶部。
规则与计算口径
指标 / 规则
口径
周目标（工作 / 个人）
本周七天内安排过的任务去重计数，按分类拆开
周完成
目标中当前状态为“完成”的件数
最后一次动过
以下最近一次：换列、开始计时或补记、安排到某天、勾选关联子项目、编辑任务
停滞预警
待办或进行中，最后一次动过距今 ≥ 21 天，卡片显示黄色“N 天没动”
僵尸任务
待办或进行中，最后一次动过距今 ≥ 30 天；从最久的开始逐张处理
等待超时
在等待中 ≥ 7 天
插单占比
本周新建任务中标为插单的比例；≥ 30% 标红
计划 🍎
当天清单所有任务的计划数相加（含已完成）；默认简单 1、普通 2、困难重要 1，可在日看板调整；计划数跟随任务，不按天单独设置
实际 🍎
当天所有计时与补记的分钟数 ÷ 20，不足 20 分钟按比例
项目进度
已完成子项目 ÷ 子项目总数；没有子项目时按关联任务计算；全部完成时进度环变绿
子项目联动
子项目生成任务卡后双向同步：任务完成则子项目打勾，勾选子项目则任务移入完成，取消则移回待办
进行中上限
默认 3，可调 1–9，超过 5 时提示；工作与个人共用名额
视觉、存储与限制
视觉与交互规范
• 颜色即含义：工作 = 蓝，个人 = 紫，完成 = 绿，等待 = 琥珀，僵尸 / 超时 = 红，🍎 计时 = 苹果红。
• 字体：标题宋体（Noto Serif SC），正文黑体（Noto Sans SC），数字等宽（JetBrains Mono）。
• 浅色、深色主题自动跟随系统；手机宽度下看板依次变为三列、两列、一列，页面不横向滚动。
• 文字从简：说明性小字只保留必要的，状态尽量用格子、圆环、颜色表达。
• 删除类操作都要二次确认；弹窗可按 Esc 或点空白处关闭。
数据存储与同步
• 每次操作后立即保存，不依赖关闭页面。
• 本地版：存在当前浏览器（localStorage），建议用 Chrome 或 Edge；无痕模式、清缓存、换浏览器会看不到数据。
• 在线版：额外存到账号私有云端，改动约 1 秒后上传；切回页面时拉取更新，以最后保存时间较新的一方为准；他人打开同一链接只看到自己的空白看板。
• 备份：导出全部数据为文本，可复制保存或导入到另一版本。
已知限制
• 在线版需要登录 claude.ai 才能打开和同步。
• 两台设备同时修改时，后保存的一方覆盖前者。
• 单份数据上限约 256 KB，接近 200 KB 时提示清理旧的已完成任务。
• 拖动排序依赖鼠标，手机上换列用 ‹ › 按钮，项目排序暂不支持触屏拖动。
